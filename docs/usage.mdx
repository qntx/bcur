title: Usage
description: L3 transport Encoder and L4 typed Ur.
---

L3 — opaque bytes plus a type token:

```rust
use bcur::{Decoder, Encoder, UrType};

let data = b"Ten chars!".repeat(10);
let mut encoder = Encoder::new(&data, 5, &UrType::new("alpha")?)?;
let mut decoder = Decoder::default();
while !decoder.complete() {
    decoder.receive(&encoder.next_part()?)?;
}
assert_eq!(decoder.message()?.as_deref(), Some(data.as_slice()));
```

`ur::encode` / `Encoder` do not parse or require CBOR. `UrType::bytes` and `Encoder::bytes` remain for untyped test payloads (matches ur-rs). They are not the crate hero.

L4 (`feature = "dcbor"`) enforces BCR-2020-005 “message MUST be dCBOR”: `typed::Ur::from_ur_string` and `typed::MultipartDecoder::message` reject non-dCBOR (`Error::Cbor`). First tag name is the UR type; the body is untagged.

```rust
use bcur::Ur;

let ur = Ur::new("test", vec![1, 2, 3])?;
assert_eq!(ur.string(), "ur:test/lsadaoaxjygonesw");
```
